# Inputs — Acme Mobile Banking

Synthetic input artifacts for the `mobile-applications` pack example run:

- `tech_plan.md` — the mobile client technical plan (the primary artifact).
- `AndroidManifest.xml` — exported components and the `acmebank://` deep-link handler.
- `Info.plist` — iOS App Transport Security posture and the custom URL scheme.
- `network_security_config.xml` — Android TLS / certificate-pinning configuration.

These describe a deliberately flawed design used to demonstrate the pack; they
are not a real application.
